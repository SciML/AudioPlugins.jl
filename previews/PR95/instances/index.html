Independent LV2 and VST3 instances

The AudioPlugins.lv2_copy, AudioPlugins.lv2_set, AudioPlugins.lv2_expect, AudioPlugins.vst3_copy, AudioPlugins.vst3_set, and AudioPlugins.vst3_expect operators are public and accessed through the AudioPlugins module.

AudioPlugins.Lv2Instance — Type
Lv2Instance(f::Function, path; kwargs...)
Lv2Instance(path; uri = "", sample_rate = 48000, block_size = 512, channels = 1)

Open an independent LV2 effect without replacing the default plugin or any other instance. Pass the same search path and URI as to lv2_open!. Pass the instance as the first argument to lv2_fill!, lv2_out, the configuration/parameter readers, and AudioPlugins.lv2_* operators. Generated nodes can pass its numeric handle instead to the lv2_* operators.

Use the do-block form to close automatically, including on exceptions, or close explicitly with lv2_close!(instance) in a finally block. Closing is idempotent; a closed handle never names a later instance. Calls into the host must be serialized: instances may coexist, but parallel calls from multiple threads are not supported. Latency is reported, not compensated.

Requires a host library built from the accompanying C sources with the instance API; see lv2_lib_path for the development override.

AudioPlugins.lv2_copy! — Function
lv2_copy!(destination::Lv2Instance, source::Lv2Instance, token) -> token

Copy the current output block of source into destination and return its input token. Both instances must have the same block size, sample rate and host channel count. Invalid handles, stale output and mismatches return NaN. The C copy allocates nothing and discards any pending destination parameter chain. Use AudioPlugins.lv2_copy(destination.handle, source.handle, token) from a generated node. Latency is not compensated.

AudioPlugins.lv2_set — Function
AudioPlugins.lv2_set(dep, id, value) -> token
AudioPlugins.lv2_set(instance, dep, id, value) -> token

Queue a control input value for the armed block. Calls may chain any number of declared parameters; a repeated id keeps the last value. Explicit process slots take precedence. A fresh input or block copy discards the queue. Values use LV2 plain units. Invalid handles, stale inputs and invalid parameters return NaN.

AudioPlugins.vst3_set(instance, dep, id, value) -> token

Queue a normalized (0–1) parameter value for the armed block. Calls may chain any number of declared writable parameters; repeated ids keep the last value. Explicit process slots take precedence. A fresh input or block copy discards the queue. Values are clamped to [0, 1] during processing. Invalid handles, stale inputs and invalid parameters return NaN.
